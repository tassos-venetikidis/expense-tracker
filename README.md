# Expense Tracker

Track your inflows and outflows of funds with this simple web app.

Supports the addition of new expense or income entities. The usage of a negative amount number denotes an expense, whereas a positive one an income infusion. Hovering over the added items reveals the delete button that appears on the left.

Made with:

- HTML
- CSS
- vanilla JavaScript
- localStorage (state persistence)
